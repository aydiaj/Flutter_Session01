# SICT235 — Codelab 01: Course Orientation & Introduction to Flutter

**Week 1 / Session 1 · 120 minutes · theory and guided discussion only**

A complete, responsive, offline-capable introductory codelab for PDB2 learners at Gaza Training Centre. This session does not require Flutter, Dart, a code editor, installation, a practical task, or a student submission.

## Open it

Open `index.html` in any modern browser, or publish this folder through GitHub Pages. There are no external CSS/JS dependencies. External documentation links are optional and require internet.

## Publish to GitHub Pages

1. Create a personal GitHub repository (for example, `flutter-codelab-01`). No organization is required.
2. Upload **the contents of this folder**, so `index.html` is in the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, your main branch, then `/(root)`; save.
4. Open the published URL once GitHub Pages finishes deployment.

## Features

- Eight guided sections, sidebar, Previous/Next, progress tracking
- Theme toggle, responsive desktop and mobile layouts
- Student-friendly original SVG diagrams and fictional illustrative app mockups
- Conceptual widget explorer, simulated UI update and optional ungraded knowledge checks
- Local, browser-only progress; no account, tracking, dependencies or submission

## Files

- `index.html` — interactive lesson
- `sources.html` — syllabus, book and official documentation references
- `css/style.css`, `js/app.js` — frontend implementation
- `images/*.svg` — original illustrations and diagrams
- `images/dash-study-mascot.webp` — compact, original course illustration of the official Flutter/Dart mascot

## Privacy and offline use

This static site does not send answers anywhere. Completion is saved only to this browser when browser storage is available. Progress is not synchronized between devices. The site itself works without internet; optional links to current Flutter documentation and the real-app showcase require connectivity.
